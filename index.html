    ForensiX documentation¶

    ForensiX is an end-to-end media forensics platform: it takes you from the first suspicious file to a calibrated, monitored detection service on your own infrastructure or any major cloud.

    • Detect manipulated and AI-generated images, video and voices with 39 commercially licensed detectors, including face swaps, lip-sync mismatches, cloned voices and physical inconsistencies. They all sit behind one API: forensix.load(name).predict(media) in Python, or POST /v1/detect over HTTP.
    • Prove what a file says about itself: C2PA Content Credentials, generator watermarks, metadata.
    • Adapt and trust the results on your media: fine-tune (including LoRA), calibrate to a false-alarm budget, and audit fairness.
    • Run it as an API and web console: locally, on Kubernetes, or on AWS, Google Cloud and Azure with one command or one click. Monitor it live.

    Status at a glance¶

    Family Models State
    audio aasist, aasist-l, rawgat-st, xlsr-aasist, xlsr-aasist-df, nes2net-x, nes2net-x-itw pretrained, parity-checked against upstream
    image univfd, rine, rine-ldm, commfor, commfor-224, safe, clipdet pretrained, parity-checked
    video gend, gend-pe, dfdet-clip, dfdc-selim, dfdc-wm pretrained, parity-checked, benchmarked on SDFVD
    audiovisual avad, syncnet, stablesyncnet pretrained, parity-checked
    audiovisual avcons, avid ForensiX models; you train them (Training)
    identity person-anomaly per-person detector from real media only; enroll in Python or the browser studio
    identity id-face, id-voice pretrained (SFace, ECAPA)
    identity id-motion ForensiX model; you train it
    physics phys-bloodflow, phys-motion, phys-lighting, phys-voice, phys-room algorithmic; phys-voice ships a reference fitted on real speech (calibrated scores), the others use provisional ranges until you fit a reference
    physics physdf runs without a graph prior; train the prior for the full system
    specialized person-detector tiny per-person model you train in seconds; superseded by person-anomaly (why)
    provenance c2pa, watermark-image, watermark-audio, metadata evidence in the file: Content Credentials, SD/SDXL and AudioSeal watermarks, metadata (Provenance)
    multimodal, graph-based none yet planned

    forensix.list_models() always gives the current list.
